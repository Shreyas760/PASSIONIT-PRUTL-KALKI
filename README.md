# PASSIONIT PRUTL KALKI Challenge

AI-powered ethical dilemma card game.

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

## Features

- User authentication
- Ethical dilemma gameplay
- Player decision tracking
- History management

## Architecture

Frontend communicates with backend APIs.
Backend handles authentication, game logic, and database operations.
